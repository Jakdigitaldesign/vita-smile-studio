# Vita Smile Studio

Crie um site institucional ONE PAGE completo, moderno e profissional para uma clínica odontológica fictícia chamada **ODONTO VITA**.

O objetivo do site é apresentar a clínica, transmitir confiança e profissionalismo e incentivar o visitante a entrar em contato pelo WhatsApp para agendar uma avaliação.

## 1. DIREÇÃO VISUAL

Criar uma identidade visual:

* Moderna
* Elegante
* Sofisticada
* Minimalista
* Acolhedora
* Profissional
* Premium, mas sem parecer excessivamente luxuosa
* Inspirada em clínicas odontológicas modernas e marcas de saúde de alto padrão

Evitar aparência genérica de template.

Utilizar bastante espaço em branco, boa hierarquia visual, bordas levemente arredondadas, sombras muito sutis e elementos visuais delicados.

### Paleta de cores

Utilizar principalmente:

* Azul petróleo / azul profundo: #123C4A
* Azul claro: #DCEFF2
* Branco: #FFFFFF
* Cinza muito claro: #F6F8F9
* Cinza para textos: #536168
* Cor de destaque suave: #6FA8B5

A cor azul profundo deve ser utilizada em títulos importantes, botões e elementos de destaque.

Não utilizar gradientes exagerados.

## 2. TIPOGRAFIA

Utilizar uma combinação elegante e moderna.

Sugestão:

* Títulos: Playfair Display ou DM Serif Display
* Textos e interface: Inter ou Manrope

Os títulos devem transmitir sofisticação, enquanto os textos devem continuar extremamente legíveis.

## 6. SEÇÃO — SERVIÇOS

**Soluções para cuidar do seu sorriso**

### Limpeza e Prevenção

Cuidados preventivos para manter dentes e gengivas saudáveis.

### Clareamento Dental

### Ortodontia

## 13. RESPONSIVIDADE

O site deve ser totalmente responsivo.

Desktop:

* Layout sofisticado
* Bastante espaço entre seções
* Hero em duas colunas
* Cards organizados em grids

Tablet:

* Ajustar espaçamentos e grids

Mobile:

* Menu hamburguer
* Hero em uma coluna
* Botões ocupando largura adequada
* Cards empilhados
* Imagens adaptadas
* Textos com tamanhos apropriados
* CTA sempre muito fácil de acessar

## 14. EXPERIÊNCIA E MICROINTERAÇÕES

Adicionar microinterações discretas:

* Hover nos botões

* Animação suave ao aparecerem as seções

* Transições de aproximadamente 200–300ms

Evitar animações exageradas.

O site deve parecer rápido, refinado e profissional.

## 19. IMPORTANTE SOBRE O DESIGN

Não quero um site com aparência de template genérico.

A referência estética deve ser:

**"Clínica odontológica premium contemporânea + branding minimalista + experiência de site de alto padrão."**

Priorizar:

* Hierarquia visual
* Tipografia elegante
* Espaçamento
* Imagens grandes
* Cards minimalistas
* Consistência visual
* Conversão para WhatsApp
* Sensação de confiança

O resultado final deve parecer um site desenvolvido por um estúdio profissional de web design e pronto para ser apresentado como projeto de portfólio.

Não adicionar funcionalidades desnecessárias como login, dashboard, banco de dados ou sistema de agendamento neste primeiro momento.

O foco é criar uma **one page institucional visualmente excelente, responsiva e orientada à conversão.**
